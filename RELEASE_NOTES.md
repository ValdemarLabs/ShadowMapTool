# ShadowMap Tool v1.3.2

This release makes generated shadows look more natural, improves how custom and transparent models are handled, and makes favorite settings easy to reuse.

## Highlights

- Added **Sun softness** for less rigid-looking projected shadow contours.
- Added reusable presets that save and load the complete shadow setup.
- Transparent parts of supported model textures, such as gaps in fences and leaves, can now let light through.
- Improved custom doodad model selection, modern **Has Shadow** overrides, and non-uniform object scaling.
- Added protection against giant domes, sky shells, and backdrop models unexpectedly darkening large areas.
- Added an **Info** button for every Advanced setting, with practical explanations and value examples.
- Changed the default sun angle so tall and elevated objects cast better-anchored shadows.
- Improved warnings so troublesome objects are easier to find in World Editor.

The full technical details are available in the [changelog](https://github.com/ValdemarLabs/ShadowMapTool/blob/main/CHANGELOG.md).

As always, **Save as copy** is the recommended first run. Open the generated copy in Warcraft III and inspect it before replacing a working map.
